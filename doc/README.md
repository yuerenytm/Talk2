# Talk2 文档

本目录是 Talk2 的文档入口。产品说明、技术选型、架构、开发约定、打包与排错都写在这里。

根目录的 `README.md`（若有）只做项目简介并链到本目录，不承载设计正文。

## 文档索引

| 文档 | 内容 |
|------|------|
| [产品介绍.md](./产品介绍.md) | 产品是什么、用什么构建、能做什么 |
| [技术选型.md](./技术选型.md) | 当前采用的技术栈 |
| [架构设计.md](./架构设计.md) | 模块边界、数据流、存储、平台适配、落地顺序 |

## 约定

- **语言**：中文正文，专有名词与包名保留英文（如 PySide6、`keyring`）。
- **写法**：只写产品是什么、选用什么、如何实现。
- **命名**：`主题.md`，主题即内容，不使用日期或作者前缀。
- **新增**：先在本页索引里加一行，再创建文件。
- **修改**：直接改对应文档；重大决策变更时在该文档末尾补「修订记录」，保持同一份文档持续更新。
- **代码**：实现以仓库源码为准；文档描述意图与约束，避免复制大段即将过时的代码。
