# 新闻简报计划

在现有对话进程上增加每日新闻：到点拉取用户配置的 RSS，用同一套 OpenAI 兼容模型摘要成 10 条，以独立窗口弹出。技术约定见 [技术选型.md](./技术选型.md) 第 5 节。聊天和 RAG 的发送路径保持原样。

## 用户怎么用

1. 打开设置，勾选「每日新闻」，填写本地时刻（默认 08:00）和 RSS 地址列表，保存。
2. 点「立即获取」可以马上拉一次，用来确认源和摘要效果，不必等到点。
3. 到达设定时刻后弹出简报窗口：10 条，每条有标题、一两句说明、来源。点击条目用系统浏览器打开原文。
4. 窗口提供「关闭」和「打开助手」。正在输入或流式回复时，简报另开窗口，不抢走输入焦点。
5. 关闭聊天主窗口后进程仍留在系统托盘，定时继续有效。托盘菜单：打开聊天、立即获取新闻、退出。没有托盘的桌面环境里，主窗口保持打开，定时在窗口存活期间生效。
6. 设置里可打开「开机自启」。登录后自动启动，以便当天到点能弹出。

同一天只弹一次。若启动时已经过了设定时刻、且当天还没弹过，补弹一次。

## 一次简报的数据流

```mermaid
flowchart LR
  Clock[QTimer检查本地时刻]
  Fetch[拉取RSS]
  LLM[摘要为10条]
  Popup[新闻窗口]
  DB[(news_digests)]

  Clock --> Fetch
  Fetch --> LLM
  LLM --> Popup
  Popup --> DB
```

拉取和摘要在工作线程里完成，主线程只负责打开窗口。模型调用失败时，窗口仍打开，展示各源最近标题里的前 10 条，并标明「未摘要」。某个 RSS 打不开时跳过该源，其余源继续用。全部源都失败时，窗口说明这次没有取到新闻，不写入空简报。

## 设置项

存在现有 `settings` 表：

| 键 | 含义 |
|----|------|
| `news_enabled` | `1` / `0` |
| `news_time` | 本地时刻，`HH:MM`，默认 `08:00` |
| `news_feeds` | 多行文本，每行一个 RSS 地址 |
| `news_last_date` | 最近一次成功弹出的本地日期 `YYYY-MM-DD` |
| `autostart` | `1` / `0` |

默认源给出一组可直接用的公开 RSS（中文与国际各若干），用户可增删。界面加在现有设置对话框：开关、时间、源列表、「立即获取」、开机自启。

## 拉取与摘要

模块放在 `talk2/core/news_fetcher.py`。

- 用 `feedparser` 读取每个地址，每源取最新若干条的标题、摘要、链接、来源名。
- 摘要截断后再送给模型，避免单次请求过长。
- 复用 `LLMClient` 的地址、密钥和对话模型，走一次非流式补全。提示词要求严格 10 条，每条包含标题、一两句说明、来源名和链接。
- 解析模型输出为结构化列表。解析失败时改用原始标题 Top 10，并标明「未摘要」。

落库表 `news_digests`：`fetched_at`、`items_json`、`raw_source_count`、`model`、是否经过摘要。密钥不进这条记录。

## 定时、托盘与自启

`talk2/core/scheduler.py` 用 `QTimer` 每 30 秒看一次本地时间。`news_enabled` 为开启、当前时刻已到 `news_time`、且 `news_last_date` 不是今天时触发一次。触发后先写下今天的日期，避免补弹和定时叠成两次。

托盘用 `QSystemTrayIcon`。关闭主窗口时隐藏到托盘，而不是退出进程；退出只走托盘菜单。启动时若 `QSystemTrayIcon.isSystemTrayAvailable()` 为假，关闭窗口仍退出，定时只在本次运行中生效。简报弹出时，若托盘可用，再调用 `showMessage()` 作一条短提醒。

开机自启由 `talk2/core/platform.py` 按系统写入：

- Windows：当前用户 Startup 快捷方式，目标为现有的 `pythonw -m talk2`
- Linux：`~/.config/autostart/talk2.desktop`

打包后的程序改为指向自身可执行文件，见 [打包.md](./打包.md)。

关闭自启时删掉对应项。

## 弹窗

`talk2/ui/news_popup.py`：独立窗口，列出 10 条。显示时 `show()`、`raise_()`；只有不在输入、也不在流式生成时才激活窗口。置顶用窗口标志尽力打开。

「打开助手」把聊天主窗口显示到前台。「关闭」只关简报。

## 代码落点

| 位置 | 改动 |
|------|------|
| `talk2/core/news_fetcher.py` | 拉 RSS、调用模型、解析 10 条、失败时用原始标题 |

| `talk2/core/storage.py` | `news_digests` 写入与最近一条读取 |

| `talk2/ui/news_popup.py` | 简报窗口 |

## 实现顺序

1. RSS 拉取、模型摘要、`news_digests` 落库；设置里可编辑源并点「立即获取」打开弹窗。
2. 每 30 秒检查本地时刻，到点弹出，当天补弹且只弹一次。
3. 托盘常驻，关闭主窗口不退出；托盘可打开聊天、立即获取、退出。
4. 开机自启开关。

第 1 步完成后就能手动看到 10 条简报。第 2 步起，应用开着就会按设定时刻自动弹。

## 验收

- 设置里保存两个 RSS 并点「立即获取」，窗口列出 10 条；点击能打开链接。
- 把时刻改成当前分钟的下一分钟，到点只弹出一次；重启后若今天已经弹过，不再补弹。
- 断开模型或填错密钥时，窗口仍出现，内容为原始标题，并标明「未摘要」。聊天记录不受影响。
- 正在输入时弹出简报，输入框里的文字还在。
- 关闭主窗口后进程仍在托盘中，到点仍能弹出；从托盘退出后进程结束。
- 打开开机自启后，对应的 Startup 项或 `talk2.desktop` 出现；关闭后该项消失。
