# 打包

Talk2 用 PyInstaller 打成单目录便携包。构建在要发布的操作系统上执行：Windows 得到 `Talk2.exe`，Linux 得到同名可执行文件。目录内带有 Qt 平台插件和 jieba 词表。HTTPS 走操作系统证书库。

## 构建

使用 Python 3.10 及以上，先安装运行依赖和 PyInstaller：

```bash
python -m venv .venv
pip install -r requirements-build.txt
python scripts/build.py
```

Windows 可执行 `scripts\build.ps1`，它会优先调用仓库里的 `.venv`。Linux 执行 `scripts/build.sh`。

产物：

| 系统 | 可执行文件 |
|------|------------|
| Windows | `dist/Talk2/Talk2.exe` |
| Linux | `dist/Talk2/Talk2` |

分发时拷贝整个 `dist/Talk2` 目录。聊天记录、知识库索引和密钥仍写在系统用户目录，不写进这个目录。双击可执行文件即可打开，没有控制台窗口。

## 开机自启

从源码运行时，设置里的开机自启指向 `pythonw -m talk2`（Linux 为 `python -m talk2`），工作目录是仓库根目录。

打包后的程序会识别冻结运行，自启改为指向该可执行文件，工作目录是 `dist/Talk2`。
