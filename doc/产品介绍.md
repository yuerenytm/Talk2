# 产品介绍

基于 Python 与 PySide6 构建的本地桌面助手，以 Qt 原生窗口渲染界面，面向 Windows 与 Linux；实现 OpenAI 兼容流式对话、Markdown 渲染、多会话管理，以及对指定文件夹中 Markdown（如 Obsidian 库）的本地 RAG 检索，历史由 SQLite 原子写入本机。

通过 Qt 信号槽与后台线程完成流式分发与主动弹窗；定时 Agent 每日拉取 RSS，用用户配置的模型摘要为 10 条新闻简报。密钥与数据存于本机，PyInstaller 便携分发，配套文档与构建脚本。
