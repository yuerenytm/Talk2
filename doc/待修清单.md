## 清单

### 1. 检索未过滤零分候选

- **现象**：关键词路只要被 FTS 的 `OR` 命中，即使归一化后是 0 分，也会进入候选并可能出现在最终 Top-K 里。
- **位置**：`talk2/core/rag.py` 的 `search()`（融合排序处）。
- **影响**：Top-K 里混入与问题无关的段落；段落数少时更明显（所有段落都会被返回）。
- **候选修法**：融合后加阈值（如 `score > 0`），或对每一路先做最小分过滤。

### 2. 缺少中文停用词表

- **现象**：`tokenize()` 只过滤纯标点，"的、了、和、是、有、什么、哪些"等虚词全部参与 FTS 查询。
- **位置**：`talk2/core/rag.py` 的 `tokenize()`。
- **影响**：虚词在多个段落里都出现，bm25 对它们给低分甚至负贡献，会稀释真正关键词的权重；同时扩大无效召回。
- **候选修法**：内置一份中文停用词表，分词后过滤；或按文档频率（DF）自动降权。

### 3. 切块粒度偏粗

- **现象**：按 Markdown 标题切块，单块上限 `MAX_CHARS = 1200`，一篇 450 字的笔记会整篇成为一块。
- **位置**：`talk2/core/rag.py` 的 `chunk_markdown()` 与 `_split_long()`。
- **影响**：命中后整块进 prompt，模型需要自己在块内定位答案；同一块里可能混多个主题。
- **候选修法**：调小 `MAX_CHARS`（如 600~800），或在没有子标题的长段落里按句子/段落再切。

### 4. 两条 system 消息

- **现象**：RAG 上下文作为一条 system 消息插入，`LLMClient.stream_chat` 又把设置里的 `system_prompt` 作为另一条 system 插到最前。
- **位置**：`talk2/ui/stream_worker.py` 的 `run()`；`talk2/core/llm_client.py` 的 `stream_chat()`。
- **影响**：最终请求里出现两条 system 消息；不同服务端对多条 system 的处理不完全一致。
- **候选修法**：在拼装时合并成一条（自定义人设在前、检索上下文在后）。

### 5. 引用列表等于全部 Top-K

- **现象**：UI 展示的引用是检索返回的全部 6 段，不区分模型实际引用了哪几段；回答里的 `[n]` 也不做校验。
- **位置**：`talk2/ui/stream_worker.py`（emit citations）、`talk2/ui/chat_window.py` 与 `talk2/ui/widgets.py`（展示引用按钮）。
- **影响**：引用可能包含模型完全没用到的段落；模型写越界编号（如 `[7]`）不会被发现。
- **候选修法**：完成后解析回答里的 `[n]`，只展示被引用的段落；越界编号做提示。

### 6. 引用落库为纯文本

- **现象**：引用以 Markdown 列表形式拼进 assistant 消息正文存储。
- **位置**：`talk2/ui/chat_window.py` 的 `_citation_suffix()` 与 `_on_completed()`。
- **影响**：重新打开会话时引用是纯文本，不能点击打开原文件。
- **候选修法**：把引用单独存一列（如 `messages.citations` JSON），加载时重建可点击按钮。

### 7. `base_url` 一个地址同时服务对话与 embedding

- **现象**：`LLMConfig.base_url` 同时用于 chat 与 embeddings 调用。
- **位置**：`talk2/core/llm_client.py` 的 `_client()`，配置来源为 `settings.base_url`。
- **影响**：无法"对话用 A 服务、向量用 B 服务"；例如 DeepSeek 提供 chat 但不提供 embeddings 接口，想启用向量检索就必须整体换服务。
- **候选修法**：为 embedding 增加独立的地址与 Key 配置（`embedding_base_url` / `embedding_api_key`），缺省时回落到主配置。

### 8. `news_digests` 只写不读

- **现象**：每次抓取都会写一条简报记录，但没有任何界面读取它。
- **位置**：写入在 `talk2/ui/news_worker.py`；表定义在 `talk2/core/storage.py`。
- **影响**：数据只进不出，无法回看往期简报。
- **候选修法**：增加"往期简报"入口，按日期列出 `news_digests` 记录。
